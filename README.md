# Fitness First

Fitness First is a fitness-focused web application developed to provide users with fitness services, meal plans, trainer details, pricing information, BMI calculation, and basic user account functionality.

## Features

* Home page for fitness service overview
* BMI calculator
* User registration and login
* Services section
* Meal plans section
* Trainer information section
* Pricing section
* Chat page
* Database-backed user functionality
* Responsive website structure

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## Purpose

This project was developed to practice full-stack web application development, frontend design, backend development with PHP, database operations using MySQL, form handling, asynchronous communication using JavaScript fetch(), and user-focused website development.
