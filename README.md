# Fitness First

Fitness First is a fitness-focused web application developed to provide users with fitness services, meal plans, trainer details, pricing information, BMI calculation, and basic user account features.

## Features

* Home page for fitness service overview
* BMI calculator
* User registration and login pages
* Services section
* Meal plans section
* Trainer information section
* Pricing section
* Chat page
* Responsive website structure

## Technologies Used

* HTML
* CSS
* PHP

## Purpose

This project was developed to practice web application development, page navigation, form handling, basic PHP usage, and user-focused fitness website design.
